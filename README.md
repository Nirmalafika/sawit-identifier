# 🌴 SawitID — Identifikasi & Estimasi Produksi Sawit

Software berbasis web untuk membantu petani kelapa sawit mengestimasi jumlah produksi Tandan Buah Segar (TBS) berdasarkan data kebun.

## ✅ Fitur
- Hitung estimasi produksi TBS per bulan & tahun
- Estimasi pendapatan berdasarkan harga TBS
- Kalender panen berdasarkan pola musim
- Panduan produktivitas sawit per fase umur
- Bisa dicetak sebagai laporan

## 🚀 Cara Pakai
1. Buka file `index.html` di browser (atau akses via GitHub Pages)
2. Isi form data kebun: luas, umur, jarak tanam, varietas
3. Klik "Hitung Estimasi Panen"
4. Lihat hasil dan jadwal panen

## 📋 Data yang Dibutuhkan
- Luas lahan (hektar)
- Umur tanaman (tahun)
- Jarak tanam
- Jenis varietas bibit
- Sistem pengairan
- Kondisi pemupukan

## 🌐 Deploy di GitHub Pages
Lihat panduan di: Settings → Pages → pilih branch main
